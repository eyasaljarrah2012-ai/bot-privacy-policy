# Privacy Policy

**Last updated:** November 2026

## Overview
This bot does not collect, store, or share any personal data from users or servers.

## Data We Access
To function properly, the bot temporarily accesses:
- Server member lists (to process commands)
- User presence/status (to provide bot features)
- Message content (to respond to commands)

This data is processed in real-time and never stored or logged.

## Data Sharing
We do not sell, trade, or share any data with third parties.

## Data Retention
No user data is retained. All processing is temporary and in-memory only.

## Contact
If you have any questions, contact us through our support server.

## Changes
We may update this policy. Continued use of the bot means you accept the updated policy.
